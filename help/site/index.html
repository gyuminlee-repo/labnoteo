Labnote Assistant 도움말

바이오파운드리 기반 합성생물학 실험을 Obsidian 노트로 기록하는 플러그인 Labnote Assistant(labnoteo)를 기능별 짧은 영상으로 보여 줍니다. 영상은 실제 플러그인 화면을 녹화한 것이고, 영상 위쪽 띠의 자막이 각 단계를 설명합니다.

영상은 labnoteo 0.105.0 기준입니다.

세부 규칙(폴더 이름 규칙, CSV 덮어쓰기 조건 등)은 이 페이지에 다시 적지 않고 보관함의 QUICKSTART(명령 팔레트 → 사용법 열기)로 연결합니다.

시작하기

설치

설정에서 제한 모드를 끄고, 커뮤니티 플러그인에서 BRAT를 설치한 뒤, BRAT의 Add beta plugin에 sblabkribb/labnoteo를 넣습니다. 설치가 끝나면 왼쪽 리본에 워크플로·샘플 아이콘이 생깁니다. BRAT 화면은 Obsidian 언어와 상관없이 영어로 나옵니다.

단계별 안내: 설치 가이드 4. Labnote Assistant 설치

연구노트 자동화 설정

연구노트 자동화 설정 (Setup research automation)은 노트 검증, 실험과 GitHub Issue 연결, Wiki 발행에 쓰는 GitHub Actions·스크립트·AI 에이전트 규칙을 보관함에 설치합니다. 탐색기에는 AGENTS.md와 QUICKSTART.md가 보이고, .github/·.labnoteo/ 같은 점 폴더는 Obsidian에 보이지 않습니다.

한눈에 보기

실험을 만들고, 워크플로와 유닛 오퍼레이션을 넣고, 본문에서 샘플을 참조하고, 진행 상태를 바꾸는 흐름을 2분 안에 보여 줍니다. 바뀐 결과는 오른쪽 워크플로 뷰와 샘플 뷰에서 확인합니다. 각 단계의 자세한 영상은 아래 링크에 있습니다.

  • 실험 생성
  • 워크플로 생성
  • 유닛 오퍼레이션 삽입
  • 샘플 자동완성
  • 실험 상태 변경

명령 찾는 법

명령은 Obsidian 명령 팔레트(Ctrl/Cmd+P)에서 찾습니다. 한국어 UI에서는 실험 생성 (Create experiment)처럼 한글과 영문이 함께 보이고, 실험 생성으로도 Create experiment로도 검색됩니다. Labnote로 검색하면 이 플러그인의 명령만 모입니다. 한눈에 보기 영상에서 영어로 검색하는 장면을 볼 수 있습니다.

우클릭 메뉴와 창(모달)의 항목은 한글만 표시됩니다(예: 표를 CSV로 내보내기). 팔레트 명령은 영어 이름을 알면 바로 찾을 수 있도록 함께 적고, 메뉴는 화면에 보이는 그대로 적기 때문입니다. 이 페이지도 팔레트 명령은 처음 나올 때 한글과 영문을 함께, 그 뒤로는 한글만 적습니다.

전체 대응표와 팔레트에 없는 기능: QUICKSTART · 명령 찾는 법

5분 따라하기

실험 만들기

명령 팔레트 → 실험 생성 (Create experiment) → 제목 입력. 입력 창 아래에 폴더 이름 기준 글자 수가 나오고, labnote/###_제목/README.labnote.md가 만들어져 바로 열립니다. 열리자마자 머리말의 author를 채우세요. 이후 만드는 워크플로의 실험자가 여기서 들어갑니다.

QUICKSTART · 1. 실험 만들기 (폴더 이름 규칙)

워크플로 뷰에서 실험 보기

리본의 상자 아이콘으로 여는 워크플로 뷰 맨 위 실험 칸에 보관함의 실험이 묶여 보입니다. 실험 검색 칸으로 거르고, 옆의 전환으로 상태별·과제별(README의 project)·논의 표시별을 오갑니다.

묶음 전환은 운영체제의 목록 상자라 영상에는 펼쳐진 목록이 찍히지 않습니다. 자막으로 고른 항목을 알려 줍니다.

진행 상태 바꾸기

명령 팔레트 → 실험 상태 변경 (Change experiment status) → 상태 선택. 상태는 어느 실험 노트에서 실행해도 그 실험의 README에 들어갑니다. 워크플로 뷰에서 실험을 우클릭 → 실험 상태 변경으로도 바꿀 수 있고, 바뀐 상태는 워크플로 뷰의 묶음에 바로 나타납니다.

QUICKSTART · 2. 진행 상태 바꾸기

논의가 필요한 곳 표시하기

질문이 떠오른 문장을 선택하고 논의 이슈 마커 삽입 (Insert issue marker)을 실행하면 @issue;ISS-…;주제 마커가 붙습니다. 실험 전체를 논의하려면 논의 표시 전환 (Toggle discussion flag)을 씁니다. push하면 GitHub Issue가 열립니다(연구노트 자동화를 설정한 보관함).

QUICKSTART · 3. 논의 표시

커밋·푸시와 이슈 확인

커밋·푸시는 Copilot에 연결한 AI 에이전트에게 "오늘 작업 커밋하고 푸시해줘"라고 말하면 됩니다. push하고 잠시 뒤 GitHub 저장소의 Issues 탭에서 마커마다 열린 이슈를 확인합니다. 이 단계는 Obsidian 밖 화면이라 영상 대신 화면 사진으로 보여 줍니다.

기록하기

워크플로 만들기

실험 README에서 워크플로 생성 (Create workflow) → 카탈로그 검색 → 별칭 입력. 한국어 UI에서는 클로닝, 조립처럼 한국어로도 검색됩니다. 만든 워크플로는 README의 체크리스트에 자동으로 등록됩니다.

QUICKSTART · 워크플로 노트 (파일 이름 규칙)

워크플로 이름 바꾸기와 복사본

탐색기에서 워크플로 노트 이름을 바꾸면 README 체크리스트의 라벨이 따라 바뀝니다. 탐색기 우클릭 메뉴로 복사본을 만들면 복사본의 별칭을 묻고, 다음 번호를 붙여 체크리스트에 등록합니다.

워크플로 번호 다시 매기기

워크플로 번호 다시 매기기 (Renumber workflows)는 번호를 001부터 빈칸 없이 다시 매기고, 체크리스트도 맞춥니다.

폴더와 체크리스트 맞추기

다른 실험에서 옮겨 오거나 복사한 워크플로는 체크리스트에 자동으로 오르지 않습니다. 폴더와 워크플로 체크리스트 맞추기 (Sync workflow checklist with folder)가 빠진 항목을 등록하고, 파일 이름과 어긋난 라벨을 옛 라벨 → 새 라벨 목록으로 보여 준 뒤 고칩니다.

우클릭으로만 쓰는 기능

README에서 우클릭 → 워크플로 삽입, 워크플로 뷰의 카탈로그 항목 우클릭 → 유닛 오퍼레이션 삽입, 파일 탐색기에서 노트 우클릭 → 표를 CSV로 내보내기. 팔레트만 훑어서는 알기 어려운 경로입니다.

유닛 오퍼레이션 넣기

워크플로 노트를 연 상태에서 유닛 오퍼레이션 삽입 (Insert unit operation) → 작업 선택 → 별칭. 문서 맨 위 목차가 헤딩 순서대로 다시 만들어집니다.

QUICKSTART · 유닛 오퍼레이션

유닛 오퍼레이션 순서 바꾸기

Obsidian 개요(Outline) 보기에서 유닛 오퍼레이션 제목을 끌어 옮기면 목차와 --- 구분선이 자동으로 정리됩니다.

날짜 넣기

날짜 삽입 (Insert date)과 날짜 및 시간 삽입 (Insert date and time)은 커서 위치에 오늘 날짜와 시각을 넣습니다. 유닛 오퍼레이션 #### Meta의 날짜 줄 끝 📅 아이콘을 누르면 날짜 칸이 열립니다.

달력 팝업은 운영체제가 그리는 창이라 영상에 찍히지 않아, 입력 칸에서 값을 바꾸는 장면으로 보여 줍니다.

표를 CSV로 내보내기

표를 CSV로 내보내기 (Export tables to CSV)는 노트 안의 표를 각각 노트이름.labnote_table1.csv로 같은 폴더에 저장합니다.

편집 중 @DNA;처럼 치면 자동완성이 열립니다. 새 DNA ID 생성을 고르면 ID를 만들어 등록하고 본문에는 참조만 넣습니다. 본문 우클릭 → 샘플 추가로도 만들 수 있습니다.

QUICKSTART · 본문에서 쓰기

샘플 뷰

리본의 시험관 아이콘으로 여는 샘플 뷰에서 샘플을 추가·편집(보관 위치 포함)·검색하고, 다 쓴 시료는 지우지 않고 폐기로 표시합니다.

QUICKSTART · 샘플 뷰

정의 보기와 사용처

본문의 참조 위에서 우클릭 → 정의로 이동으로 그 샘플의 정의 창을 엽니다. 샘플 뷰에서 우클릭 → 사용처 보기는 그 샘플을 쓰는 노트 목록을 보여 주고, 고르면 그 노트를 엽니다.

타입 변경과 전역으로 이동

잘못 고른 타입은 샘플 뷰 우클릭 → 타입 변경으로 바꿉니다. 바뀔 노트 목록을 확인하면 노트의 참조 ID 접두사도 함께 바뀝니다. 여러 실험에서 함께 쓰는 샘플은 전역으로 이동으로 Global에 둡니다.

이 실험의 시료를 표로

이 실험의 시료 목록 삽입 (Insert sample list of this experiment)은 이 실험의 로컬 샘플과 본문이 참조하는 전역 샘플을 ID·별칭·설명·보관 위치·범위·폐기 열의 표로 넣습니다.

사용자 정의 샘플 타입

설정 → Labnote Assistant → 사용자 정의 샘플 타입에 배지 같은 타입을 더하면 바로 @배지로 자동완성됩니다. 타입 이름에는 글자·숫자·_만 씁니다.

출력본 스캔

워크플로 노트를 실험 기록지로 출력해 실험실에서 손으로 적고, 사진이나 스캔을 PC로 보내면 종이의 QR을 읽어 원래 노트의 그 유닛 오퍼레이션 아래에 붙입니다. 서버 없이 PC의 Obsidian 안에서 처리하며, 데스크톱 Obsidian 전용입니다.

기록지 출력

워크플로 노트에서 명령 팔레트 → 실험 기록지 출력 (Print experiment worksheet). 노트 위쪽 QR 아이콘(노트 바코드 보기)을 누르면 노트 ID와 QR을 볼 수 있고, 그 창에서도 출력할 수 있습니다. 출력 창에서 유닛 오퍼레이션을 고르고(실험실(HW) 유닛 오퍼레이션은 미리 켜져 있음) 용지 크기를 정한 뒤 출력을 누릅니다.

페이지마다 노트 ID가 담긴 QR이 두 곳에 찍힙니다. 기록지에는 적힌 내용만 인쇄되고, 비어 있는 절은 제목만, 비어 있는 Meta 값은 빈칸으로 나옵니다. 인쇄 배율은 100%(실제 크기)로 두세요.

인쇄 창은 운영체제가 그리는 창이라 영상은 출력 창까지만 보여 줍니다. 인쇄 창이 뜨지 않으면 브라우저에서 열기로 시스템 브라우저에서 인쇄합니다.

출력본 스캔 가이드 · 2. 기록지 출력

스캔 붙이기

리본의 스캔 아이콘이나 명령 팔레트 → 스캔 가져오기 (Import scanned pages)로 창을 열고 사진·PDF·zip을 끌어다 놓습니다. 끝나면 스캔 결과 창이 "1쪽: 1쪽 붙임"처럼 알려 주고, 페이지마다 노트 열기와 되돌리기가 있습니다. 노트에는 그 유닛 오퍼레이션 끝의 #### Worksheet scans에 폭 200px 썸네일로 붙고, 설명 끝의 원본 보기로 원본 크기를 엽니다.

매번 끌어다 놓지 않으려면 설정 → 바코드와 스캔의 스캔 폴더에 PC 폴더(Google Drive 폴더, 복합기 폴더, 카카오톡 받은 파일 등)를 지정합니다. 스캔만 넣는 폴더는 전용 폴더, 다른 파일과 섞인 폴더는 공유 폴더로 고릅니다. QR을 읽지 못한 페이지는 미인식 스캔 할당으로 직접 붙입니다.

Slack으로 보내기

Slack을 쓰면 휴대폰으로 찍은 기록지 사진을 내 Slack 봇에게 DM으로 보내 붙일 수 있습니다. 출력본 스캔 가이드의 매니페스트를 붙여 넣어 Slack 앱을 만들고 xoxb-로 시작하는 봇 토큰을 복사합니다. 설정 → 바코드와 스캔 → Slack으로 스캔 받기(선택)에 Slack 봇 토큰을 넣고 봇에게 DM을 고른 채 연결을 누릅니다. 화면에 나온 labnote-123456 같은 연결 코드를 봇에게 DM으로 보내면 봇이 스레드에 "연결되었습니다"라고 답합니다.

그다음 사진은 스레드가 아니라 대화창에 새 메시지로 보냅니다. 이 PC의 Obsidian이 켜져 있으면 약 90초마다 확인해 👀 반응을 달고, 결과를 그 메시지의 스레드 답글로 알려 줍니다. 연결은 PC 한 대에만 하고, 끊을 때는 같은 곳의 연결 해제를 누릅니다. Slack 앱 화면이라 영상 대신 화면 사진으로 보여 줍니다.

AI 도우미

Obsidian 안에서 쓰는 보조 기능입니다. 영상은 로컬 Ollama의 qwen3.5:9b 모델로 녹화했고, 응답을 기다리는 구간은 빨리 감았습니다. 모델과 언어에 따라 결과 글은 달라집니다.

AI 제공자 설정

설정 → Labnote Assistant → AI 프로바이더의 프로바이더를 Ollama나 OpenAI-compatible로 고르고 Ollama 엔드포인트(또는 OpenAI 엔드포인트)와 모델을 채웁니다. 기본값은 비활성화됨이라 그대로 두면 AI 명령이 동작하지 않습니다.

Method 초안

유닛 오퍼레이션 안에서 AI: Method 섹션 초안 작성 (AI: Draft Method section)을 실행하면 그 블록의 #### Method 절이 채워집니다.

결과 요약

AI: 결과 요약 (AI: Summarize results)은 노트 전체를 읽고 커서 다음 줄에 > [!note] AI 요약 콜아웃을 넣습니다.

샘플 정의 추출

AI: 샘플 정의 추출 (AI: Extract sample definitions)은 본문에 적힌 시료를 샘플 대장에 등록하고 "새로 N개, 건너뜀 M개"로 알려 줍니다. 본문에는 넣지 않으니 결과는 샘플 뷰에서 봅니다.

어시스턴트에게 요청

AI: 어시스턴트에게 요청 (툴 사용) (AI: Ask assistant (uses tools))에 목표를 적으면 모델이 Labnote 도구로 보관함을 고칩니다. 쓰기 전에 매번 확인을 받고, 허용한 변경은 바로 노트에 들어갑니다. 모델이 마지막에 답을 주면 창으로 보여 주며, 그 답은 노트에 넣기를 눌러야 노트에 들어갑니다.
